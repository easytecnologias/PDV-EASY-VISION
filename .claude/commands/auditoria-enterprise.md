# Auditoria Enterprise do Easy PDV

Execute uma auditoria completa do projeto Easy Auditoria PDV.

Use as skills:

- architecture-auditor
- false-positive-investigator
- ai-pipeline-reviewer
- distributed-pdv-reviewer
- performance-profiler
- security-reviewer
- code-simplifier
- auto-refactor-planner

## Tarefa

Analise o projeto inteiro e gere `RELATORIO_AUDITORIA_ENTERPRISE.md` com:

1. Resumo executivo.
2. Mapa da arquitetura.
3. Fluxo de um cupom do PDV ao dashboard.
4. Fluxo de um alerta suspeito.
5. Causa provável dos falsos positivos.
6. Patches mínimos recomendados.
7. Plano de refatoração em PRs.
8. Riscos de segurança.
9. Gargalos de performance.
10. Testes necessários.

Não altere código nesta primeira execução. Apenas analise.
