# Plano de refatoração segura

Use `auto-refactor-planner`, `architecture-auditor` e `code-simplifier`.

## Tarefa

Gere um plano com PRs pequenos para melhorar o projeto sem parar produção.

Cada PR deve ter:

- objetivo;
- arquivos tocados;
- risco;
- teste;
- rollback.

Não aplique código sem aprovação.
